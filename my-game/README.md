# Memory Match Game - Neon Syntax Edition

A modern, responsive memory card game featuring a "Neon Syntax" theme inspired by developer aesthetics. Built with **Svelte 5** and **Vite**, this project demonstrates modern state management, responsive CSS layouts, and polished user experience design.

![Game Screenshot](public/screenshot.png)

##  Features

-   **Neon Syntax Theme**: A cyberpunk-inspired aesthetic featuring glowing **Lucide** icons and a deep slate palette.
-   **Responsive Design**: Fully optimised for all devices.
    -   **Desktop**: Side-by-side layout with a dedicated "How to Play" sidebar.
    -   **Mobile**: Stacked layout with touch-optimised interactions.
-   **Fast Play Logic**: No more waiting! The game logic handles rapid clicks intelligently, cancelling timeouts for a snappy, fluid experience.
-   **High Score System**: Tracks your moves and saves your **Best Score** to LocalStorage, challenging you to improve.
-   **Confetti Celebration**: A satisfying particle explosion triggers when you match all pairs.

##  Tech Stack

-   **Framework**: [Svelte 5](https://svelte.dev/) (using Runes for local reactivity)
-   **Build Tool**: [Vite](https://vitejs.dev/)
-   **Icons**: [Lucide Svelte](https://lucide.dev/)
-   **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
-   **Styling**: Vanilla CSS (CSS Variables, Flexbox, Grid, Media Queries)

##  Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/nicola-empower/memory-match-game.git
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
